# ARGUS Releases

Офіційні релізи та дистрибутиви **ARGUS** для Windows 10 / 11 (x64).

- Завантажити останню версію можна у розділі [Releases](https://github.com/PIFAG0R0302/ARGUS-Updates/releases).
